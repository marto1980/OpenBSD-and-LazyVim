Useful plugins (apart from the obvious ones):

1. coding.luasnip: Very useful. Provides snippet expansion via LuaSnip, works well with nvim-cmp.

2. coding.mini-comment: Lightweight commenting plugin, integrates with Treesitter. Handy for TS/Angular and LaTeX % comments.

3. coding.neogen: Generates documentation for functions/classes. Useful if you like JSDoc or typed comments.

4. editor.aerial: Symbol outline for classes/functions. Very useful for large TS/Angular projects.

5. editor.illuminate: Highlights other instances of the word under cursor. Useful.

6. editor.harpoon2: Quick file bookmarking. Optional, useful for personal workflow.

7. editor.navic: Shows code context in statusline (e.g., in Lualine). Useful.

8. editor.refactoring: Provides refactor actions for TS/JS. Definitely useful.

9. editor.snacks.picker

11. ui.mini-indentscope: Highlights current scope. Useful.

12. ui.treesitter-context: Shows current function/class at top. Very useful.

13. util.project: Project management. Useful.
