Useful plugins (apart from the obvious ones):
1. lang.text (vimtex)

2. coding.luasnip: Very useful. Provides snippet expansion via LuaSnip, works well with nvim-cmp.

3. coding.mini-comment: Lightweight commenting plugin, integrates with Treesitter. Handy for TS/Angular and LaTeX % comments.

4. coding.neogen: Generates documentation for functions/classes. Useful if you like JSDoc or typed comments.

5. editor.aerial: Symbol outline for classes/functions. Very useful for large TS/Angular projects.

6. editor.illuminate: Highlights other instances of the word under cursor. Useful.

7. editor.harpoon2: Quick file bookmarking. Optional, useful for personal workflow.

8. editor.navic: Shows code context in statusline (e.g., in Lualine). Useful.

9. editor.refactoring: Provides refactor actions for TS/JS. Definitely useful.

10. editor.snacks.picker

12. ui.mini-indentscope: Highlights current scope. Useful.

13. ui.treesitter-context: Shows current function/class at top. Very useful.

14. util.project: Project management. Useful.
