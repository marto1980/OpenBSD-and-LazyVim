7. Install rust nightly:
 7.1 Look at this manual: https://www.openbsd-desktop.rocks/posts/update-rust/
 7.2 Clone the build repo as documented here: https://github.com/semarie/build-rust

To find the rust date you can use the find-archives.sh script, available in the manual above, beforehand commenting out the actual downloads to prevent downloading unnecessary files. You can check the specific rust version by visiting the page for the respective date that the find-archives.sh script outputs, e.g. https://static.rust-lang.org/dist/2025-12-22 and checking the channel-rust- files.
Make sure to provide the correct environment variables in the ~/.build_rust.conf file, as described in the 7.1 manual, e.g:

-----------------------------------------------------------------------------------------------
SUDO=doas
# The URL where to download the rustc source code packaged for building
# Note: there is no slash at the end
distfiles_rustc_base="https://static.rust-lang.org/dist/2025-12-22"
# The Rust compiler used to compile the other Rust version will be used
# from there. /usr/local is the path to use when using the default Rust
# installed using pkg_add(1).
# Once you built a Rust version (e.g. at /path/to/build-rust/install_dir/current),
# use the new path in rust_base_dir to use the new Rust version to compile another
# one.
rust_base_dir=/home/marto/build/build-rust/install_dir/nightly

----------------------------------------------------------------------------------------------
export PATH=$HOME/build/build-rust/install_dir/nightly/bin:$PATH
export LD_LIBRARY_PATH=$HOME/build/build-rust/install_dir/nightly/lib:$LD_LIBRARY_PATH

Useful plugins (apart from the obvious ones):
1. lang.text (vimtex)

2. coding.luasnip: Very useful. Provides snippet expansion via LuaSnip, works well with nvim-cmp.

3. coding.mini-comment: Lightweight commenting plugin, integrates with Treesitter. Handy for TS/Angular and LaTeX % comments.

4. coding.neogen: Generates documentation for functions/classes. Useful if you like JSDoc or typed comments.

5. editor.aerial: Symbol outline for classes/functions. Very useful for large TS/Angular projects.

6. editor.illuminate: Highlights other instances of the word under cursor. Useful.

7. editor.harpoon2: Quick file bookmarking. Optional, useful for personal workflow.

8. editor.navic: Shows code context in statusline (e.g., in Lualine). Useful.

9. editor.refactoring: Provides refactor actions for TS/JS. Definitely useful.

10. editor.snacks.picker

12. ui.mini-indentscope: Highlights current scope. Useful.

13. ui.treesitter-context: Shows current function/class at top. Very useful.

14. util.project: Project management. Useful.
